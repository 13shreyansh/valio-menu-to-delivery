Open by design

The same brain, open to any agent

Everything this page does is also an MCP server, an open standard. A hotel chain's own procurement agent, Claude or ChatGPT can connect to it, and Valio still enforces each customer's prices, assortment and mandate on its own side.

MCP endpoint

Why Valio keeps control

  • Customer-specific: every price and stock call carries the customer id; only shortlisted products are quoted, as Valio's API guide asks.
  • Mandate on Valio's side: submit_order re-checks allergens, spend limit and substitutions, so a careless buyer agent cannot bypass them.
  • Explainable: each draft order carries allocations to dishes and a decision log with rule ids.
  • Share of wallet: if ordering a whole menu from Valio takes one tap, kitchens buy more of it from Valio.
